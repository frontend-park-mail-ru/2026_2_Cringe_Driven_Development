### Правила оформления Pull Requests

1. Ветка создается с названием `cdd-###`, где ### - номер issue
2. Коммиты должены быть названы по шаблону `<тип>: <описание>`
3. При создании Pull Request'а нужно указать в описании ссылку на issue
4. Для того, чтобы выкатить задачу нужно получить апрув от [Ярослава](https://t.me/Yaroslav738)
