# Проверка штатных связей GitHub

Этот документ добавлен только для контролируемой проверки связи `Closes #236`
при временно отключённом автозакрытии issues после merge. Эксперимент относится
к [frontend#235](https://github.com/Cringe-Driven-Development-Team/frontend/issues/235).

Правка не меняет приложение, CI или CD. Результаты эксперимента сохраняются
локально; наличие этого документа не означает успешную проверку или выкатку.
